# Jeu de course automobile 2D

## Présentation :
Ce projet consiste à programmer et développer un jeu de course automobile en 2D de type mario kart 
en langage python en utilisant les techniques de la POO.
Ce jeu permet à deux joueurs de conduire leur voiture simultanément à l'aide du clavier.

## Fonctionnalités du jeu :

- Affichage du circuit et des différentes cases
- Affichage et déplacement simultané des voitures
- Contrôle des deux joueurs au clavier
- Menu principal
- Sélection du circuit
- Écran de course
- Menu pause
- Écran de victoire.
- Affichage des informations durant la course

## Commandes du jeu :

### Joueur 1 :

Touche Z  : Accélérer
Touche S : Freiner 
Touche A : Tourner à gauche 
Touche E : Tourner à droite 
Touche Tabulation : Utiliser un objet

### Joueur 2 :

Touche flèche haut  : Accélérer
Touche flèche bas : Freiner 
Touche flèche gauche : Tourner à gauche 
Touche flèche droite : Tourner à droite 
Touche shift : Utiliser un objet
